Quick Start

  1. Add the visual to your Power BI report from AppSource. With no fields yet it shows a getting-started page.
  2. Drag a numeric field to X Value and another to Y Value.
  3. Optionally add a text/category field to Category for color grouping.
  4. In the Format Pane → Reference Lines, set the Y Reference Value to split the plot horizontally.
  5. Under Upper Zones, set the number of vertical dividers (0–4) and their X values.
  6. PRO Under Lower Zones, add independent vertical dividers below the Y-ref for a truly asymmetric layout.

All options are always visible in the Format Pane; paid ones are marked (Pro). While you edit a report without a licence, Pro options you turn on are shown working under a Pro preview watermark and Power BI shows how to get a licence. In reading view, in published reports, and where Power BI cannot check licences (Publish to Web, embedding, PDF/PowerPoint export), the free result is shown, without a watermark.

Interaction

Click any zone background, or a point, to cross-filter other visuals — all points in that zone are selected and the rest of the report responds. Click the same zone again to deselect (toggle). Clicking outside any zone clears the selection. Right-click opens the Power BI context menu.

Each zone announces its label and number of points to screen readers. In Windows high contrast mode the visual uses the theme colors and marks the selected zone with a thicker border.

FAQ

Why is the upper zone layout different from the lower?
That is the core concept of the Asymmetric Matrix: the number of vertical divisions above and below the Y-reference line can be completely independent. Configure Upper Zones and Lower Zones separately in the Format Pane. Dividers below the Y-reference require a Pro license.

Can I use a negative Y reference value?
Yes. The Y ref accepts any numeric value, including negative numbers and decimals.

The axis range jumps when I filter the report. How do I keep it stable?
Enable Fixed axis range (Pro) in Format Pane → Axes. The axis domain expands to cover all data seen since the last full data reload, but never shrinks.

My zone cards or data labels are not showing.
Zone Cards and data labels are Pro features. In reading view they are shown only with an active licence.

How do I add an X or Y axis title?
Fill X axis title (Pro) and Y axis title (Pro) in Format Pane → Axes.

I bought the Pro plan. When does it activate?
The visual detects the licence automatically when the report is opened or refreshed. Microsoft notes it can take up to an hour for a new licence to be recognised: refresh the browser (F5) or close and reopen Power BI Desktop. A licence is required per user.
