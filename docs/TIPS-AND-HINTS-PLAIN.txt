TIPS & HINTS — ASYMMETRIC MATRIX
==================================


GETTING STARTED
---------------
Add at minimum X Value and Y Value to see your data.
The visual shows a landing page until both fields are mapped.

The Category field groups points by color (one color per unique value).
Without it, all points share a single default color.


FIELD WELLS
-----------
· Category     — No — Text/dimension. One color per unique value.
· X Value      — Yes — Numeric measure. Horizontal axis.
· Y Value      — Yes — Numeric measure. Vertical axis.
· Size         — No  — Numeric measure. Maps values to bubble radius.
· Tooltips     — No  — Up to 10 measures. All appear in the hover tooltip.


FORMAT PANE — REFERENCE LINES
------------------------------
Set Y Reference Value to the threshold that separates upper and lower halves
(average, target, or zero). Change the line style to Dashed or Dotted to make
it less dominant.


FORMAT PANE — UPPER ZONES
--------------------------
· Number of vertical lines (above): 1–4 to create 2–5 column zones.
· Line value: X threshold where the divider appears.
· Zone label: text centered in the zone background.
· Zone color + Zone opacity (0–100): color-coded risk or priority layout.
· Label background color/opacity: subtle fill behind label text for legibility.


FORMAT PANE — LOWER ZONES (Free: 1 zone · Pro: up to 5 zones)
--------------------------------------------------------------
Free tier: the lower half is a single zone.
  Configure its label, color and opacity.

Pro tier: add up to 4 independent vertical dividers below the Y-ref.
  Lower positions are completely independent of upper ones —
  enabling asymmetric layouts not possible with standard 2×2 matrices.


FORMAT PANE — AXES
------------------
· Tick font size / Tick color: adjust to match your report theme.
· Tick decimals: 0 for whole numbers, 1–5 for decimals, -1 for auto (K/M).
· Show gridlines: disable for a cleaner look when zone colors are visible.
· X axis title / Y axis title [PRO]: label your axes.
· Fixed axis range [PRO]: axes never shrink during cross-filtering.
  Recommended for dashboards where stable spatial positioning matters.


FORMAT PANE — DATA POINTS
--------------------------
· Default radius: applies when no Size field is mapped.
· Opacity (0–100): lower slightly (e.g. 70) if points overlap.
· Data labels [PRO]: shows Category value above each point.
  Best with fewer than ~30 points.


FORMAT PANE — ZONE CARDS (PRO)
-------------------------------
Displays a count badge in the top-left of each zone.
Shows how many data points fall in that zone.
Clickable — same cross-filter behavior as clicking the zone.


FREE vs PRO
-----------
Feature                           Free   Pro
Upper zones (up to 5)              Yes    Yes
1 lower zone                       Yes    Yes
Zone labels, colors, opacity       Yes    Yes
Category grouping                  Yes    Yes
Bubble size                        Yes    Yes
Tooltips (up to 10 fields)         Yes    Yes
Cross-filter on zone click         Yes    Yes
Lower asymmetry (up to 5 zones)     No    Yes
Axis titles                         No    Yes
Fixed axis range                    No    Yes
Data labels on points               No    Yes
Zone count cards                    No    Yes


TIPS & BEST PRACTICES
---------------------
· Design your zones before setting values.
  Sketch on paper: how many zones above/below, and what each means.

· Use asymmetry intentionally.
  Common pattern: 3 zones above (Low/Mid/High) and 2 zones below.

· Coordinate zone colors with your report palette.
  Traffic-light (green/yellow/red) works well. Keep opacity 30–50%.

· Fixed axis range for presentations (Pro).
  Stable axes make it easy to track where points move when filtering.

· Add 2–3 tooltip measures for context (Revenue, Margin, Region).

· Data labels work best with fewer than 30 points.
  For denser data, rely on tooltips instead.


EXAMPLE CONFIGURATIONS
----------------------
3x2 Asymmetric Matrix:
  Upper: 2 vertical lines → 3 zones (Low / Medium / High)
  Lower [Pro]: 1 vertical line → 2 zones (Acceptable / At risk)
  Y-ref: average of Y Value measure

Classic 2x2:
  Upper: 1 vertical line → 2 zones
  Lower [Pro]: 1 matching line (or 0 for single lower zone in Free)

Performance vs Risk Scatter:
  X axis: Performance score (0–100), Y axis: Risk score (0–100)
  Y-ref: 50 (midpoint)
  Upper: 2 lines at X=33 and X=66
  Lower [Pro]: 1 line at X=50


TROUBLESHOOTING
---------------
· Points not visible:
  Check that X Value and Y Value are numeric measures, not text fields.

· Zone dividers in wrong position:
  Line values are in the same units as your X Value measure.

· Cross-filter not working:
  Verify other visuals support cross-filtering.
  Clicking outside all zones clears the selection.

· Lower Zones lineCount option missing:
  This is a Pro feature. Appears only with an active Pro license.

· Axis titles not showing:
  Axis titles are a Pro feature. Appears in Format Pane → Axes with Pro license.
