TIPS & HINTS — BUBBLE & SCATTER CHART 1.1 (formerly Asymmetric Matrix)
=======================================================================


GETTING STARTED
---------------
1. Category: one bubble per value (customer, product, project).
   Without it (and without Legend) the whole table is one bubble.
2. X axis and Y axis: the two measures to compare.
3. Optional: Size (bubble area), Legend (colour by group),
   Tooltips (up to 10 measures).
4. Click "Quadrants at the average" in the tips bar, or pick a style template.

Until X and Y are in, the visual shows a start screen with the steps.


FIELD WELLS
-----------
· Category  — needed for more than one bubble — one bubble per value
· Legend    — optional — colour by group; rows of the zone table
· X axis    — required — measure, horizontal position
· Y axis    — required — measure, vertical position
· Size      — optional — bubble AREA proportional to the value
· Tooltips  — optional — up to 10 measures; report page tooltips supported

Up to 30,000 rows. With Category and Legend: one bubble per combination.


THE ONE MISTAKE TO AVOID: PERCENTAGES AS COLUMNS
------------------------------------------------
Power BI aggregates X, Y and Size per bubble (Sum by default). A margin %
column summed per customer gives 300% for ten rows at 30%. Use a measure:

   Margin % = DIVIDE(SUM(Sales[Margin]), SUM(Sales[Sales]))


LINES AND ZONES
---------------
· Y line: fixed value, average or median of the bubbles' Y.
· Upper dividers: 0–4. Divider 1 can be at the average or the median.
· Lower half:
    Same dividers as above — quadrants (default)
    One zone               — the 1.0 look
    Own dividers (Pro)     — different dividers below the line
· Up to 5 zones per half, each with label, colour and opacity.
· Average and median are unweighted (one value per bubble) and follow
  the filters. For a weighted reference, type a fixed value.


STYLE TEMPLATES
---------------
Classic · Four quadrants · Minimal · Soft · Dark background.
A template fills only what you have not set. Choosing one resets the
colours it defines (also a fixed bubble colour or an fx rule), never
your lines.


FORMAT PANE
-----------
· Style template — template, show setup tips
· Bubbles        — colour by, colour (fx), opacity, size, border, data labels
· Legend         — show, position, font size, colour, share of each group
· Y line         — show, at, value, colour, style
· Upper zones    — dividers, zones, zone labels
· Lower zones    — lower half, dividers (own), zones, zone labels
· Axes           — font, ticks, decimals (−1 = model format), log X/Y,
                   gridlines, plot background, fixed range (Pro), titles
· Trend line     — Pro
· Zone table     — Pro: % of row, % of column, points, size field
· Zone counts    — Pro: count and optional %


INTERACTION
-----------
· Bubble click      — filters by that point (Ctrl adds)
· Zone click        — all bubbles in the zone
· Legend click      — that group
· Zone table click  — cell, zone or group (Pro)
· Empty area        — clears
· Keyboard          — Tab, arrows, Enter/Space, Escape, Shift+F10
· Bookmarks restore the selection.


PRO AND THE PREVIEW
-------------------
Pro: own lower dividers, zone table, trend line with R², zone counts,
fixed axis range. Without a licence, while editing, Pro settings you
turn on are drawn under a "Pro preview" watermark. Readers without a
licence see the free chart, with no watermark.


TIPS
----
· Start at the average; switch to fixed thresholds when you know them.
· Use own dividers where the decision differs above and below the line.
· Name the zones: "Grow", "Protect", "Fix price", "Review".
· Zone table: % of row = where each group sits; % of column = what a
  zone is made of; size field = how much value sits in each zone.
· Fixed axes when flipping through a slicer in front of an audience.
· Log scale for skewed measures: every value on that axis must be above 0.
· Data labels hide the ones that would collide; for hundreds of
  bubbles rely on tooltips.


TROUBLESHOOTING
---------------
· One bubble only         — add a field to Category.
· Strange percentages     — DIVIDE measure, not a column.
· Log scale stays linear  — a value ≤ 0 on that axis.
· No legend               — Colour by = Auto, Show legend on.
· Zone table missing      — turn it on, enlarge the visual; Pro.
· "No data for the current filters" — no bubble with both X and Y.
· 1.0 report looks different — Lower half → One zone; Colour by →
  Each category; Axis titles off.
