Key Benefits
  • Break free from the symmetric 2×2 constraint
  • Upper and lower thresholds are fully independent
  • Zone click cross-filters the entire report page
  • Bubble size field for a 3rd data dimension
  • Up to 10 tooltip fields for rich hover context
  • No external dependencies — fast, lightweight SVG
  • Works in Desktop, Service, Embedded & Mobile
Tips
  • Sketch your zone layout on paper before setting values
  • Keep zone opacity at 30–50% so points stay readable
  • Use a traffic-light color scheme (green / yellow / red)
  • Enable Fixed axis range (Pro) for stable presentations
  • Add 2–3 tooltip measures — Revenue, Margin, Region
  • Data labels work best with fewer than 30 points
  • Set tick decimals to 0 for whole-number axes
