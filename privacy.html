Privacy Policy

Visual: Asymmetric Matrix  |  Publisher: TCViz  |  Last updated: 2026-08

Data processed

The Asymmetric Matrix visual processes only the data fields you explicitly add to its field wells (Category, X Value, Y Value, Size, Tooltips). This data originates from your Power BI dataset and is used exclusively for rendering the chart within your report.

No external network requests

The visual does not make any HTTP requests, does not contact external servers, and does not send your data anywhere outside your Power BI environment.

No local file access

The visual does not read from or write to your local file system.

No cookies or persistent storage

The visual does not use cookies. No data is persisted outside the Power BI report file (.pbix). Visual settings are stored inside the .pbix file as part of the standard Power BI report format.

License validation

If you have a Pro license, the visual uses the official IVisualLicenseManager API provided by Power BI to verify your license status. This check is performed entirely within the Power BI service and does not involve external network calls by the visual itself.
