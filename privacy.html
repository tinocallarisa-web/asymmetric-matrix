Privacy Policy

Visual: Bubble & Scatter Chart (formerly Asymmetric Matrix)  |  Publisher: TCViz  |  Last updated: 2026-10-24  |  Applies to: version 1.1.0.0 and later

Data processed

The Bubble & Scatter Chart visual processes only the data fields you explicitly add to its field wells (Category, Legend, X axis, Y axis, Size, Tooltips). This data originates from your Power BI dataset and is used exclusively for rendering the chart within your report.

No external network requests

The visual does not make any HTTP requests, does not contact external servers, has no telemetry or analytics, and does not send your data anywhere outside your Power BI environment. It requests no special privileges from Power BI.

The links on the visual's start screen (support page, product page, video) open only when you click them, through Power BI.

No local file access

The visual does not read from or write to your local file system.

No cookies or persistent storage

The visual does not use cookies or browser storage. No data is persisted outside the Power BI report. Visual settings are stored inside the report as part of the standard Power BI report format.

License validation

To check whether you have a Pro license, the visual uses the official IVisualLicenseManager API provided by Power BI. This check is performed entirely within Power BI and does not involve external network calls by the visual itself.
